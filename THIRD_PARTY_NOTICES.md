# Visual Design Credits

Pirate's visual system uses adapted interaction ideas from these free Uiverse UI elements:

- **0xnihilism / thin-crab-36**: offset card/button shadow and diagonal button sheen. <https://uiverse.io/0xnihilism/thin-crab-36>
- **Rodrypaladin / orange-liger-90**, a variation of **Rodrypaladin / funny-grasshopper-66**: colorful media-led card and geometric framing. <https://uiverse.io/Rodrypaladin/orange-liger-90>

The adaptations are in `src/components/ui.tsx`, `src/app/+html.tsx` and the hero components. They are React Native/platform-aware adaptations, not installed Uiverse components. Uiverse states that its UI elements are published under MIT: <https://uiverse.io/mit>. Copyright remains with the respective creators.

## Command Menu Reference

The [shadcn/ui command documentation](https://ui.shadcn.com/docs/components/command) informed search/keyboard interaction expectations. The palette is an original React Native implementation; no shadcn, cmdk or Radix source component was copied or installed.

## Original Artwork

The blue hatchback/warehouse diagrams and geometric decoration are original application vector/layout artwork. No stock photography, external fonts, remote animation players or external image hotlinks are required. A generated raster resource was evaluated but rejected because the service returned a generating placeholder; it is not shipped.
